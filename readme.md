# Lumina Creative

A modern, responsive creative agency and portfolio website built with clean semantic HTML5 and CSS3.

## Features
- **Responsive Layout:** Optimized for desktop, tablet, and mobile devices using CSS Flexbox and media queries.
- **Interactive Gallery:** Grid-based portfolio showcase highlighting creative works and photography.
- **Clean Navigation:** Minimalist header navigation with active state indicators.
- **Contact & Social Links:** Comprehensive footer section featuring quick contact info and social media icons.

## Tech Stack
- **HTML5:** Semantic document structure and accessible markup.
- **CSS3:** Custom properties (CSS variables), Flexbox, and responsive design breakpoints.
- **Font Awesome & Google Fonts:** Vector icons and custom typography.

## Getting Started
1. Clone the repository: `git clone git@github.com:mhsakibb/LUMINA.git`
2. Open `index.html` in your favorite web browser.
